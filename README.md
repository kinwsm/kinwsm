# kinwsm

我正在探索让 ChatGPT 参与项目讨论、让 Codex 在本地执行与验证的协作方式。

## 项目

### [Git Project Handoff Skill](https://github.com/kinwsm/git-project-handoff-skill)

一个可安装的 Codex skill：通过项目 GitHub 仓库中的 `HANDOFF.md` 传递明确任务，保留请求版本、执行回执和验收证据。

`ChatGPT 讨论与读取共享文档 → Git 交接 → 本地 Codex 执行 → ChatGPT 读取结果`

[了解工作流程与安装方法](https://github.com/kinwsm/git-project-handoff-skill#readme) · [查看 skill 指令](https://github.com/kinwsm/git-project-handoff-skill/blob/main/SKILL.md)

这个仓库发布的是协作指引；实际跨端连接还需要项目授权的 GitHub 访问和本地监听器。
